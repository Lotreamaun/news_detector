# content-viewing Specification

## Purpose
Даёт пользователю просмотреть полный распознанный текст закона в удобном виде прямо в Telegram через WebApp (Mini-App), открываемый кнопкой из сообщения или уведомления, рядом с саммари и ссылкой на оригинал.

## Requirements

### Requirement: Кнопка «Полный текст» в сообщениях
Сообщение с саммари закона SHALL содержать кнопку «Полный текст», открывающую Telegram WebApp (Mini-App) с полным текстом этого закона. Кнопка появляется в доставке саммари (по команде и по кнопке force-summarize) и в уведомлениях о законе. Ссылка на оригинал на правовом портале при этом SHALL оставаться доступной в том же сообщении.

#### Scenario: Открытие WebApp из сообщения с саммари
- **WHEN** пользователь нажимает кнопку «Полный текст» в сообщении с саммари
- **THEN** открывается WebApp с полным текстом этого закона, а ссылка на оригинал остаётся в сообщении

#### Scenario: Открытие WebApp из уведомления
- **WHEN** пользователь нажимает кнопку «Полный текст» в уведомлении о новом законе
- **THEN** открывается WebApp с полным текстом этого закона

### Requirement: Полный текст закона в WebApp
WebApp SHALL показывать полный текст закона, полученный при распознавании (OCR) и сохранённый для документа, в виде обычного текста после заголовка (без блока-кода и без вложенного скролла — единый скролл страницы). Сверху после заголовка SHALL показываться дата подписания, если она извлекаема. Служебный хвост («подписано эл. подписью», ФИО подписанта, данные электронной подписи) SHALL удаляться, оставляя только суть закона + дату. Таблицы, записанные Markdown-разметкой `|...|` с разделителем `|---|---|`, SHALL рендериться как HTML `<table>`; остальной Markdown в обычном тексте SHALL стрипаться. Данные для просмотра SHALL получаться по `external_id` из URL кнопки. Если распознанный текст отсутствует, SHALL показать сообщение и ссылку на оригинал. При непредвиденном формате SHALL показать экранированный текст как есть + ссылку, не ломаясь.

#### Scenario: Полный текст доступен
- **WHEN** пользователь открывает WebApp для документа, у которого есть распознанный текст
- **THEN** WebApp показывает заголовок, дату подписания сверху (если есть), обычный текст сути без служебного хвоста и без блока-кода, таблицы отрендерены как HTML

#### Scenario: Хвост подписи фильтруется
- **WHEN** распознанный текст содержит хвост «подписано эл. подписью» / ФИО / электронная подпись
- **THEN** хвост удалён, показана только суть + дата подписания

#### Scenario: Таблица в тексте
- **WHEN** текст содержит Markdown-таблицу `|...|` с разделителем `|---|---|`
- **THEN** таблица отрендерена как HTML `<table>`, остальной текст показан как обычный (без Markdown-символов)

#### Scenario: Распознанный текст отсутствует
- **WHEN** пользователь открывает WebApp для документа без распознанного текста
- **THEN** WebApp показывает сообщение, что текст недоступен, и ссылку на оригинал на портале

#### Scenario: Фолбэк для непредвиденного формата
- **WHEN** формат текста непредвиден (не таблица и не обычный текст)
- **THEN** WebApp показывает экранированный текст как есть + ссылку на оригинал, без падения

### Requirement: Пометка о распознанном тексте
WebApp SHALL явно помечать показываемый текст как распознанный искусственным интеллектом с возможными ошибками (дисклеймер «распознано с помощью ИИ»), поскольку текст получен OCR-распознаванием скана документа.

#### Scenario: Пометка в WebApp
- **WHEN** пользователь просматривает полный текст в WebApp
- **THEN** WebApp показывает пометку «распознано с помощью ИИ» и/или дисклеймер о возможных ошибках

### Requirement: Открытие WebApp по HTTPS
Кнопка WebApp SHALL открываться только по HTTPS-адресу (ограничение Telegram WebApp). Система SHALL позволять задать публичный базовый URL WebApp через конфигурацию; открытие кнопки по этому URL SHALL не требовать перенастройки бота для смены хостинга WebApp.

#### Scenario: Настроен публичный HTTPS-адрес
- **WHEN** администратор задал публичный HTTPS-адрес WebApp в конфигурации
- **THEN** кнопка «Полный текст» открывает WebApp по этому адресу

#### Scenario: Публичный адрес не задан
- **WHEN** публичный HTTPS-адрес WebApp не задан в конфигурации
- **THEN** кнопка «Полный текст» не добавляется в сообщения, а прочие функции (саммари, ссылка на оригинал) продолжают работать
