## Purpose

Позволяет пользователю получить справку по всем доступным командам бота через команду `/help`.

## Requirements

### Requirement: Команда /help выводит справку по командам

Бот SHALL отвечать на команду `/help` сообщением со списком всех доступных команд и кратким описанием каждой.

#### Scenario: Запрос справки
- **WHEN** пользователь отправляет `/help`
- **THEN** бот отправляет сообщение с перечнем команд: `/start`, `/test`, `/latest`, `/help` и их описаниями

### Requirement: Справка содержит актуальный список команд

Список команд в ответе `/help` SHALL включать все реализованные на момент версии команды бота.

#### Scenario: Все команды отображаются
- **WHEN** пользователь отправляет `/help`
- **THEN** ответ содержит упоминание каждой команды: `/start`, `/test`, `/latest`, `/help`
