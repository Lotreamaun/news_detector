## Purpose

Позволяет пользователю запросить саммари конкретного закона явно — командой — и протестировать кнопку «Сделать саммари» без ожидания новых публикаций.

## Requirements

### Requirement: Команда `/notify_me <external_id>`

Команда `/notify_me` SHALL отправлять вызывающему пользователю уведомление с кнопкой «Сделать саммари» для закона с указанным `external_id`, если такой закон есть в БД. Команда используется для проверки кнопки и форс-саммари без новых законов.

#### Scenario: Закон найден
- **WHEN** пользователь вызывает `/notify_me <external_id>` и закон с таким `external_id` есть в БД
- **THEN** пользователю отправляется уведомление с кнопкой «Сделать саммари»

#### Scenario: Закон не найден
- **WHEN** пользователь вызывает `/notify_me <external_id>`, а закона с таким `external_id` в БД нет
- **THEN** пользователю отправляется сообщение с пояснением, что закон не найден

#### Scenario: Аргумент отсутствует
- **WHEN** пользователь вызывает `/notify_me` без `external_id`
- **THEN** пользователю отправляется подсказка с правильным использованием команды

### Requirement: Индикация создания саммари

При нажатии кнопки «Сделать саммари» пользователь SHALL незамедлительно получить обратную связь (индикатор загрузки/спиннер или сообщение «Саммари в процессе создания…»), чтобы бот не выглядел зависшим, пока идёт генерация саммари.

#### Scenario: Пользователь нажимает кнопку, начинается генерация
- **WHEN** пользователь нажимает «Сделать саммари» и генерация саммари ещё не завершена
- **THEN** пользователь видит индикатор процесса / сообщение «Саммари в процессе создания…»

### Requirement: Результат в исходном сообщении (для кнопки)

Для кнопки «Сделать саммари» сгенерированное саммари SHALL отображаться в том же сообщении, где была кнопка, а кнопка «Сделать саммари» SHALL быть удалена. Новое отдельное сообщение с результатом для кнопки SHALL не создаваться.

#### Scenario: Саммари готово, кнопка исчезает
- **WHEN** генерация завершена по нажатию кнопки
- **THEN** в исходном сообщении отображается заголовок, саммари и ссылка, а кнопка «Сделать саммари» пропадает

### Requirement: Общий месячный лимит с кнопкой

`/notify_me`, `/summary` и кнопка «Сделать саммари» SHALL делить единый месячный лимит принудительных саммаризаций на пользователя (10 в месяц по умолчанию).

#### Scenario: Счётчик общий
- **WHEN** пользователь использует и кнопку, и `/summary` в течение одного месяца
- **THEN** их счётчики пополняют один общий лимит

### Requirement: Переиспользование сохранённого саммари

Если для `external_id` в БД уже есть сохранённое саммари (`article.summary`), система SHALL вернуть его без повторного обращения к LLM: не выполняются ни загрузка текста/OCR, ни генерация саммари. Это применимо к кнопке «Сделать саммари» и к `/summary`. Счётчик месячного лимита при этом SHALL не увеличиваться.

#### Scenario: Саммари уже сохранено
- **WHEN** пользователь вызывает `/summary <id или ссылка>` или нажимает кнопку, и в БД уже есть `article.summary` для этого `external_id`
- **THEN** пользователю показывается сохранённое саммари, повторная LLM-генерация не выполняется, счётчик месячного лимита не увеличивается

### Requirement: Команда `/summary <id или ссылка>`

Команда `/summary` SHALL принудительно саммаризировать закон, указанный либо голым `external_id`, либо прямой ссылкой на страницу правового портала (из ссылки извлекается `external_id`). Саммаризация: получить текст (при отсутствии — OCR через GigaChat), сформировать саммари и отправить вызывающему пользователю. Подчиняется месячному лимиту принудительных саммаризаций на пользователя.

#### Scenario: Успешная саммаризация
- **WHEN** пользователь вызывает `/summary <external_id>`, сохранённого саммари нет, и текст/саммари получены заново
- **THEN** пользователю отправляется саммари, запись обновляется (если закон есть в БД), счётчик месячного лимита увеличивается

#### Scenario: Саммаризация по ссылке
- **WHEN** пользователь вызывает `/summary <URL страницы правового портала>`
- **THEN** система извлекает `external_id` из ссылки и выполняет саммаризацию этого закона

#### Scenario: Текст недоступен
- **WHEN** пользователь вызывает `/summary <external_id или ссылка>`, но получить текст не удалось (нет текста и OCR не дал результата)
- **THEN** пользователю отправляется сообщение об ошибке, счётчик месячного лимита не увеличивается

#### Scenario: Лимит исчерпан
- **WHEN** пользователь вызывает `/summary <external_id>`, но месячный лимит уже исчерпан
- **THEN** пользователю отправляется сообщение о лимите, саммаризация не выполняется
