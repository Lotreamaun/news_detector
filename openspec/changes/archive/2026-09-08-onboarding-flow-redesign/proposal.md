## Why

Ручное тестирование продукта реальным инженером показало: текущий `/start` для нового пользователя сразу показывает 3 кнопки и не даёт кратчайшего пути к демонстрации пользы. Нужно сжать первый экран до одного действия и показать ценность (пример уведомления) раньше, чем что-либо ещё просить у пользователя.

## What Changes

- Новый экран `/start` для **нового** пользователя: короткое приветствие без списка команд, одна кнопка "Как это работает?" — заменяет текущие 3 кнопки (`Настроить` / `Пропустить → Все` / `Показать пример`).
- По нажатию "Как это работает?" бот присылает тестовое уведомление, переиспользуя существующую функцию `show_example` без изменений её логики.
- После тестового уведомления показывается экран с призывом подписаться на канал и кнопкой "Проверить подписку" (сама механика проверки — предмет отдельного change `channel-subscription-gate`, здесь она только встраивается в последовательность экранов).
- После подтверждённой подписки открывается существующий мастер выбора уровней силы закона (`Настроить` / `Пропустить → Все`, callback `wizard:setup`/`wizard:skip`) — сам визард не меняется, меняется только условие/момент его показа.
- Экран `/start` для уже зарегистрированного пользователя (`is_new=False`) не меняется.
- Путь к настройке фильтров для нового пользователя удлиняется на один явный шаг (подписка на канал) — принято осознанно (см. грилл-сессию, Q1/Q4): подписка обязательна для регулярных уведомлений, а тестовая демонстрация пользы всё равно происходит раньше гейта.

## Capabilities

### New Capabilities
- `onboarding-flow`: последовательность экранов первого `/start` для нового пользователя — приветствие → кнопка «Как это работает?» → тестовое уведомление → гейт подписки на канал → мастер выбора фильтров.

### Modified Capabilities
- `law-force-filter`: требование «Онбординг-визард шага «Сила»» — момент запуска визарда для нового пользователя меняется с «сразу на `/start`» на «после подтверждения подписки на канал».

## Impact

- `app/bot/handlers.py` — `start()` переписывается для ветки нового пользователя (текст, клавиатура, порядок шагов).
- Зависит от change `channel-subscription-gate` — кнопка «Проверить подписку» и вызов `is_subscribed` определены там; этот change использует их, не переопределяет.
- `show_example` (тестовое уведомление) и `level_wizard_handler` (визард) переиспользуются без изменений внутренней логики — меняется только точка входа/условие вызова.
