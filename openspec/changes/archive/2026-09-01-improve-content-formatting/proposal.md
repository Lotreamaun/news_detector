## Why

В текущих выдаваемых пользователю текстах (саммари в `/latest`, `/summary`, уведомлениях) встречаются артефакты HTML-разметки (`<br />`, теги, служебные вставки), текст подан «сплошным» потоком без логического выделения, а для полного текста документа пользователю приходится уходить на правовой портал и листать сканы PDF. Это портит восприятие и удобство чтения законов прямо в Telegram.

## What Changes

- Нормализовать текст на выходе: убрать `<br />`, HTML-теги и прочие артефакты разметки — включая заголовки/названия документов (фикс: `<br />` в title, напр. «…№ 111<br /> „Об утверждении…“»).
- Привести сообщения к аккуратному читаемому виду средствами Telegram (MarkdownV2) **во всех сообщениях по умолчанию**: `/latest`, `/summary`/кнопка и уведомления — жирный заголовок, выделение ключевых пунктов, чистые переходы (фикс: раньше красиво было только после принудительной саммаризации).
- Ссылку на оригинал на правовом портале **сохранять всегда**.
- Убрать дисклеймер «⚠️ Текст распознан ИИ, возможны ошибки» из сообщений бота — он излишен для саммари; дисклеймер показывается только внутри WebApp (см. `law-text-webapp`) вверху перед текстом закона.

## Capabilities

### New Capabilities
- `content-formatting`: нормализация текста (включая заголовки), Markdown-разметка **во всех сообщениях по умолчанию**, сохранение ссылки на оригинал (дисклеймер перенесён в WebApp).

## Impact

- `app/bot/handlers.py` — доставка саммари/уведомлений, формирование текста сообщений (MarkdownV2) во всех местах по умолчанию, ссылка на оригинал; убрать дисклеймер из `_format_summary`/`_summary_final`; починить `notify_me` (убрать leftover `WEBAPP_URL`, отправка с `parse_mode="MarkdownV2"`); нормализовать title перед экранированием.
- `app/services/scheduler.py` — `_build_notification`/`_notify_users`: MarkdownV2-форматирование уведомлений по умолчанию, убрать `_AI_DISCLAIMER_TEXT`, нормализовать title.
- `app/services/rss_parser.py` — нормализовать title в `_entry_from_item` уже при сохранении в БД (убрать `<br />` и др. теги).
- Новых внешних API не добавляется. Дисклеймер «распознано с помощью ИИ» — внутри WebApp (`law-text-webapp`), в сообщениях бота не показывается.
