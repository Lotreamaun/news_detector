## Why

`/latest` показывает последние ФКЗ/ФЗ за 30 дней — в обычный день там ничего нового, а законы по фильтру пользователь и так получает уведомлениями. Не хватает ответа на вопрос «что вообще опубликовано сегодня» — на портале это ~500 актов в будний день (≈95% региональные), и сейчас их нельзя посмотреть целиком: дневной дайджест показывает только подходящие под фильтр и не больше `DIGEST_ID_CAP` (30) в Mini-App.

## What Changes

- **BREAKING** Команда `/latest` удаляется полностью (обработчик, меню команд, справка, приветствие, спека). Реальных пользователей нет — замена без переходного сообщения.
- Новая команда `/today`: тизер со всеми актами, опубликованными сегодня (`published_at` = сегодняшняя дата по Москве), **без** учёта `UserFilter`, без демо-статьи:
  - заголовок с общим числом и счётчики групп «Федеральные / Региональные» (+ «Прочие», только если не пусто);
  - до 3 самых важных актов дня (федеральные раньше региональных; среди федеральных — по значимости уровня, затем по внутренней оценке важности);
  - кнопка Mini-App «Все за сегодня» (при заданном `WEBAPP_URL`);
  - пустой день — «Сегодня пока ничего не опубликовано».
- Группа акта определяется по `external_id` (`eoNumber` портала): первые две цифры — код субъекта, `00` — федеральный уровень; не 16 цифр → «Прочие». Классификатор уровня (`level`) и пользовательские фильтры не меняются.
- Новый режим Mini-App «сегодня» (`/app?view=today`) и лёгкий эндпоинт списка актов за сегодня; дату определяет сервер (сегодня по Москве), другие дни через страницу недоступны; сверху — надпись-пояснение с датой. Группы «Федеральные» (раскрыта) / «Региональные» (свёрнута) / «Прочие», без потолка числа документов; тексты подгружаются только при раскрытии карточки; поиск по заголовку на клиенте. Региональные упорядочены по `external_id` — акты одного региона идут подряд.
- Остаток дневного дайджеста сверх технического потолка теперь доступен через `/today` (раньше — через `/latest`).
- Устаревшие упоминания в спеках (`/test`, `/notify_me`) заодно приводятся к фактическому списку команд.

## Capabilities

### New Capabilities
- `today-digest`: команда `/today` — выборка актов за сегодняшний день, группировка по `eoNumber`, порядок важности, тизер-сообщение и Mini-App-страница дня с поиском.

### Modified Capabilities
- `bot-handlers/latest`: требование удаляется целиком (REMOVED) — заменено `today-digest`.
- `bot-handlers/help`: список команд в справке — `/today` вместо `/latest`, актуальный перечень (`/start`, `/today`, `/settings`, `/summary`, `/help`).
- `channel-subscription-gate`: в перечне защищённых команд `/today` вместо `/latest` (и без несуществующей `/notify_me`).
- `content-formatting`: сценарий форматирования по умолчанию — для `/today` вместо `/latest` (требование заменяется эквивалентным под новым именем: удалить сценарий через MODIFIED нельзя).
- `law-force-filter`: исключение из фильтрации — `/today` (все акты за день) вместо `/latest`.
- `digest-notifications`: документы сверх технического потолка дайджеста доступны через `/today`.

## Impact

- Код: `app/bot/handlers.py` (удалить `latest`, добавить `today` и сборку тизера, тексты `HELP_TEXT`/приветствия/фолбэков примера), `app/main.py` (регистрация обработчика, `BotCommand`), новый модуль чистых правил `app/services/today.py` (группа, порядок, выбор топ-3, «сегодня по Москве»), `app/webapp/server.py` (режим `today`, эндпоинт списка за сегодня, поиск, ленивая загрузка), комментарии в `app/services/scheduler.py` и `app/models/article.py`.
- API Mini-App: новый `GET /today_list` (JSON без текстов, всегда за сегодня по Москве) и режим страницы `/app?view=today`; существующие `/app?ids=`, `/app?external_id=`, `/full_text`, `/summarize` не меняются. Как и остальные маршруты чтения, без авторизации.
- БД и конфигурация: без изменений (ни миграций, ни новых переменных `.env`).
- Документация: `README.md`, `CLAUDE.md`.
- Связано: issue #8 (фильтр по регионам) — коды субъектов из `eoNumber`; выбор региона в Mini-App `/today` отложен до него.
