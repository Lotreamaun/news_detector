- [x] 1.1 `PORTAL_TZ` (`Europe/Moscow`), `portal_today(now=None) -> date` и `day_bounds(d)` — границы `[D 00:00 UTC, D+1 00:00 UTC)` под формат хранения `published_at`

- [x] 1.3 `importance_key(article)`: группа → ранг уровня федеральных (`IMPORTANT_LEVELS` → `DECREE` → `GOV_RESOLUTION` → `DEPARTMENTAL` → прочее) → `importance` по убыванию (NULL после оценённых) → блок `BB` у региональных → `external_id`; `pick_top(articles, n=3)`

- [x] 1.5 Ручная проверка на копии БД (`data/backups/…`) скриптом в scratchpad: группы за 07.10 и 08.10 (федеральные ≈ число `0001…`, «Прочие» пусто), топ-3 за 08.10 и за «тихий» день 06.10, граница суток для `now` = 00:30 МСК
