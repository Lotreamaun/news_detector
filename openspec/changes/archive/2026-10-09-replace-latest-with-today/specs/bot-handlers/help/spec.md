## MODIFIED Requirements

### Requirement: Команда /help выводит справку по командам

Бот SHALL отвечать на команду `/help` сообщением со списком всех доступных команд и кратким описанием каждой.

#### Scenario: Запрос справки
- **WHEN** пользователь отправляет `/help`
- **THEN** бот отправляет сообщение с перечнем команд: `/start`, `/today`, `/settings`, `/summary`, `/help` и их описаниями

### Requirement: Справка содержит актуальный список команд

Список команд в ответе `/help` SHALL включать все реализованные на момент версии пользовательские команды бота и не SHALL упоминать удалённые команды. Служебные команды администратора (`/test_digest`, `/admin`) в справку не входят.

#### Scenario: Все команды отображаются
- **WHEN** пользователь отправляет `/help`
- **THEN** ответ содержит упоминание каждой команды: `/start`, `/today`, `/settings`, `/summary`, `/help`

#### Scenario: Удалённая команда не упоминается
- **WHEN** пользователь отправляет `/help`
- **THEN** ответ не содержит `/latest`
