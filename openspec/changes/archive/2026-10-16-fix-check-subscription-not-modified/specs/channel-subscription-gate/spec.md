## MODIFIED Requirements

### Requirement: Кнопка «Проверить подписку»
Система SHALL предоставлять пользователю с `channel_verified = False` кнопку «Проверить подписку», по нажатию на которую запускается проверка из требования «Проверка подписки на канал». При успешной проверке система SHALL показать подтверждение и разблокировать дальнейший шаг онбординга (настройку фильтров). При неуспешной проверке кнопка SHALL оставаться доступной для повторной попытки. Повторное нажатие, при котором результат проверки и показанное сообщение не изменились, SHALL обрабатываться так же, как первое: пользователь получает ответ на нажатие, обработчик не завершается ошибкой, а сообщение и кнопка остаются прежними.

#### Scenario: Успешная проверка по кнопке
- **WHEN** пользователь с `channel_verified = False` нажимает «Проверить подписку» и оказывается подписан
- **THEN** система подтверждает подписку и открывает следующий шаг (настройку фильтров)

#### Scenario: Повторная попытка после неудачи
- **WHEN** пользователь нажимает «Проверить подписку», не будучи подписанным
- **THEN** система сообщает об отсутствии подписки и оставляет кнопку «Проверить подписку» доступной для повторного нажатия

#### Scenario: Повторное нажатие без изменения результата
- **WHEN** пользователь нажимает «Проверить подписку» повторно, не будучи подписанным, и сообщение уже сообщает об отсутствии подписки
- **THEN** пользователь получает уведомление «Подписка не найдена», сообщение и кнопка «Проверить подписку» остаются без изменений, ошибка не возникает

#### Scenario: Двойное нажатие подписанным пользователем
- **WHEN** подписанный пользователь быстро нажимает «Проверить подписку» дважды, и второе нажатие обрабатывается, когда сообщение уже заменено на «Подписка подтверждена!»
- **THEN** обработчик не завершается ошибкой, сообщение с кнопками настройки фильтров остаётся без изменений
