## Context

`app/bot/handlers.py` уже содержит два хендлера (`start`, `test_gigachat`) с паттерном: `_session_maker(context)` → `async with session` → ответ через `update.message.reply_text`. Добавляются два новых хендлера по этому же паттерну.

## Goals / Non-Goals

**Goals:**
- `/latest` — выборка 10 последних статей из БД, форматирование в читаемый список
- `/help` — статическая справка по командам

**Non-Goals:**
- Фильтрация по дате/типу (planned in Этап 4, отдельно)
- Пагинация (при масштабировании — отдельная задача)
- Inline-режим и клавиатуры

## Decisions

### `/latest` — сортировка и лимит

**Решение:** `select(Article).order_by(Article.id.desc()).limit(10)`

- `id` — автоинкрементный PK, Guaranteed ordering, быстрый индекс
- Альтернатива: `published_at DESC` — надёжнее по смыслу, но `nullable=True` (статьи без даты окажутся в конце). `id` проще и достаточен.

### Форматирование вывода

**Решение:** MarkdownV2 с экранированием спецсимволов.

- Telegram поддерживает HTML и Markdown. MarkdownV2 — стандарт PTB, проще для ссылок `[текст](url)`.
- Символы `_`, `*`, `[`, `]`, `(`, `)`, `~`, `` ` ``, `>`, `#`, `+`, `-`, `=`, `|`, `{`, `}`, `.`, `!` требуют escape через `\`. Используем `telegram.helpers.escape_markdown(text, version=2)`.
- Альтернатива: HTML — не требует escape, но менее компактный синтаксис. Выбор в пользу MarkdownV2 для единообразия с PTB-стилем.

### `/latest` — пустой результат

**Решение:** проверка `len(articles) == 0` → `reply_text("Пока нет обработанных законов")`.

### `/help` — статический текст

**Решение:** константа `HELP_TEXT` (многострочная строка) в `handlers.py`. Список команд обновляется вручную при добавлении нового хендлера.

## Risks / Trade-offs

- [Экранирование MarkdownV2] → использовать `escape_markdown` из `telegram.helpers` для всех пользовательских строк. Если escape пропущен — Telegram вернёт 400 Bad Request. Место: перед `reply_text` экранируем заголовки и саммари.
- [Лимит 4096 символов] → 10 статей с длинными саммари (~280 символов) ≈ 3000–3500 символов. В пределах лимита. Если саммари будут длиннее — сообщение не поместится. Mitigation: обрезаем каждое саммари до 200 символов при выводе.
