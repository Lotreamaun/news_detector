## ADDED Requirements

### Requirement: Запуск при недоступном Telegram
Если при старте процесса Telegram Bot API временно недоступен (таймаут, сетевая ошибка, ошибка на стороне Telegram), система SHALL NOT завершать процесс, а SHALL повторять подключение с паузами, пока Telegram не ответит, и затем продолжать обычный запуск. Неверный токен бота SHALL по-прежнему останавливать запуск с понятной ошибкой в логе.

#### Scenario: Таймаут Telegram при старте
- **WHEN** контейнер запускается, а первый запрос к Telegram Bot API завершается таймаутом
- **THEN** процесс не завершается, в логе видны повторы подключения, и после того как Telegram ответил, бот запускается как обычно: проверка портала, WebApp, рассылки

#### Scenario: Telegram недоступен несколько минут
- **WHEN** Telegram Bot API не отвечает первые 5 минут после старта
- **THEN** процесс всё это время работает и повторяет подключение, а не уходит в цикл перезапусков контейнера

#### Scenario: Неверный токен
- **WHEN** контейнер запускается с неверным `TELEGRAM_BOT_TOKEN`
- **THEN** запуск останавливается с ошибкой о неверном токене, повторов нет
