## 1. Очередь в `app/services/gigachat.py`

- [x] 1.1 Тип `Priority = Literal["user", "background"]`; модульное состояние: флаг «поток занят» и две `collections.deque` ожидающих `asyncio.Future` (`user`, `background`) с комментарием, зачем очередь на процесс (один поток у ключа, клиентов много)
- [x] 1.2 `_release()`: передать поток первому неотменённому ожидающему из `user`, затем из `background` (флаг остаётся «занят»); ожидающих нет — снять флаг
- [x] 1.3 Асинхронный контекст-менеджер `_stream_slot(priority)`: свободно и никто не ждёт → занять без `await`; иначе `Future` в деку своего приоритета и ждать; отмена ожидания — убрать `Future` из деки, а если поток уже был передан — сразу `_release()` (design D2); выход из блока (в т.ч. по исключению/отмене) — `_release()` в `finally`
- [x] 1.4 Лог ожидания: если слот получен не сразу — `logger.info` с приоритетом, временем ожидания и числом вызовов впереди на момент постановки (design D6); без ожидания — без записи
- [x] 1.5 Публичная `calls_ahead_of_user() -> int` с docstring: `1` при занятом потоке + число неотменённых ожидающих `user`; только чтение (design D5)
