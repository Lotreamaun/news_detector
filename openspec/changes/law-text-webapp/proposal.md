## Why

При отправке pdf закона на OCR мы и так получаем полный текст документа, но сейчас он сохраняется в БД и не показывается пользователю: из сообщения с саммари приходится уходить на правовой портал и листать сканы. Это ограничивает удобство: весь распознанный текст уже есть, осталось собрать его в читаемый вид и дать открыть в Telegram WebApp (Mini-App) по кнопке.

Telegram WebApp открывается только по HTTPS-ссылка, поэтому выносится в отдельную фичу (в `improve-content-formatting` Mini-App намеренно исключён).

## What Changes

- Добавить в конфиг настройки WebApp: `WEBAPP_HOST`, `WEBAPP_PORT`, `WEBAPP_URL` (публичный HTTPS-адрес).
- Запустить лёгкий бэкенд-сервер WebApp: отдаёт HTML-страницу и API, возвращающее полный текст закона по `external_id` (из `original_text` в БД).
- Фронтенд Mini-App: аккуратное форматирование и просмотр полного текста закона, пометка «распознано с помощью ИИ» (дисклеймер), ссылка на оригинал на портале, кнопка возврата/закрытия.
- Добавить кнопку «Полный текст» (WebApp) в сообщения с саммари (`/summary`, кнопка force-summarize) и в уведомления `_build_notification`.
- Ссылка на оригинал правового портала сохраняется всегда; WebApp — дополнение, а не единственный способ доступа.
- Публичная ссылка WebApp раздаётся по HTTPS (внешний хостинг/прокси); код и настройки — в боте.

## Capabilities

### New Capabilities
- `content-viewing`: просмотр полного текста закона в Telegram WebApp (Mini-App) по кнопке из сообщения/уведомления: бэкенд API по `external_id`, фронтенд-страница с дисклеймером об ИИ и ссылкой на оригинал.

## Impact

- `app/core/config.py` — новые поля `WEBAPP_HOST` / `WEBAPP_PORT` / `WEBAPP_URL` + валидация.
- `app/main.py` — старт WebApp-сервера вместе с ботом (`post_init`).
- `app/bot/handlers.py` — кнопка «Полный текст» в доставке саммари (`_deliver`).
- `app/services/scheduler.py` — кнопка «Полный текст» в `_build_notification`.
- Новое: `app/webapp/` — бэкенд (API по `external_id`, HTML-страница) на aiohttp; фронтенд — статичная страница внутри пакета.
- Модели: используется существующий `original_text` (Article), миграций БД нет.
- Документация: `.env.example`, `README.md` (WebApp, HTTPS-хостинг).
- Внешние зависимости: aiohttp (или аналог) для HTTP-сервера.
