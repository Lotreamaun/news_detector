## Why

Третий срез онбординга — фильтр по региону. Пользователю из Забайкалья не нужны законы Москвы, и наоборот. Нужен ввод свободного текста («Забайкальский край», «Чита», «Москва» с опечатками) с нормализацией и подтверждением, чтобы не заставлять листать 89 регионов.

## What Changes

- Модель: расширить `UserFilter` (`dimension=region`) + `Article.region` (ISO-код субъекта / `all` / `federal`), default «Все регионы».
- Справочник регионов: 89 субъектов РФ + города/области/края/республики + алиасы (`Москва`, `Московская область`, `МСК`), включая сокращения.
- Ввод региона: свободный текст в визарде шаг 3/3 «Регион» — пользователь пишет название, система приводит к нормальной форме (лемматизация `pymorphy2`, нижний регистр, `ё→е`, удаление `г.`, `обл.`, `край`), делает нечёткий поиск (fuzzy, `rapidfuzz`/`difflib`, порог 80), определяет лучший регион и показывает предположение.
- Подтверждение: Inline-кнопки `[Да, это Забайкальский край]` / `[Нет, ввести ещё раз]`; при «Да» — сохраняет `region=75` (пример), при «Нет» — просит ввести снова (до 3 попыток, затем fallback «Все»).
- Классификатор `Article.region`: из `title`/`summary` (fallback `original_text` первые 1000 знаков) — поиск упоминания региона по тому же справочнику + леммам, иначе `federal`/`all`.
- Применение: `scheduler._notify_users` и `handlers.latest` фильтруют по `region` (OR внутри измерения, AND между измерениями `level`+`sphere`+`region`).
- Остальные вопросы (пагинация 89, алиасы, хранение города vs региона) — решить на реализации.

## Impact

- `app/models/user_filter.py` / `app/models/article.py`: добавить `region`.
- Новый `app/services/region_dictionary.py` (89 субъектов + алиасы) + `app/services/region_resolver.py` (нормализация, лемматизация, fuzzy).
- `app/services/region_classifier.py` (для `Article.region`).
- `app/bot/handlers.py`: шаг визарда «Регион» (текстовый ввод + подтверждение Inline).
- `app/services/scheduler.py`, `app/bot/handlers.py:latest`: фильтр по региону.
- Зависимости: `pymorphy2`, `rapidfuzz` (или `difflib` из stdlib).
- Без LLM, без внешних API.
