## Purpose
Позволяет пользователю получать законы только своего региона, вводя название города/области/края в свободной форме с нормализацией, нечётким поиском и подтверждением.

## ADDED Requirements

### Requirement: Хранение фильтра по региону
Система SHALL хранить для каждого пользователя выбранный регион (ISO-код субъекта, city → region, или `all` для «Все регионы») с дефолтом «Все». Фильтр SHALL сохраняться между перезапусками.

#### Scenario: Новый пользователь без настройки
- **WHEN** пользователь только зарегистрировался и не проходил визард региона
- **THEN** система считает его фильтр как «Все регионы»

#### Scenario: Сохранение региона
- **WHEN** пользователь подтвердил «Да, это Забайкальский край» (код 75)
- **THEN** система сохраняет `region=75` и показывает его при повторном `/settings` → `Регион`

### Requirement: Распознавание региона по свободному вводу
Система SHALL принимать от пользователя свободный текст (название города/области/края, с возможными опечатками), приводить к нормальной форме (нижний регистр, `ё→е`, удаление `г.`, `обл.`, `край`, лемматизация) и нечётко сопоставлять со справочником 89 субъектов (+ алиасы `МСК`→`Москва`/`Московская область`). Система SHALL возвращать одно лучшее предположение с оценкой схожести.

#### Scenario: Корректный ввод
- **WHEN** пользователь ввёл «Забайкальский край»
- **THEN** система определяет регион `Забайкальский край` (75) с высокой оценкой

#### Scenario: Ввод с опечаткой
- **WHEN** пользователь ввёл «Забайкалский край» (пропущена буква)
- **THEN** система всё равно определяет `Забайкальский край` (fuzzy ≥80)

#### Scenario: Город вместо региона
- **WHEN** пользователь ввёл «Чита»
- **THEN** система определяет регион `Забайкальский край` (по справочнику городов)

#### Scenario: Неизвестный ввод
- **WHEN** введённый текст не сопоставим ни с одним регионом (оценка <60)
- **THEN** система просит ввести ещё раз (до 3 попыток, затем fallback «Все»)

### Requirement: Подтверждение предположения
Система SHALL показывать пользователю своё предположение и просить подтвердить Inline-кнопками `[Да]` / `[Нет, ввести ещё раз]` (или `[ОК]`). При «Да» — сохраняет, при «Нет» — просит повторный ввод.

#### Scenario: Подтверждение верно
- **WHEN** система показала «Это Забайкальский край?» и пользователь нажал «Да»
- **THEN** фильтр сохраняется и визард переходит к завершению

#### Scenario: Подтверждение неверно
- **WHEN** пользователь нажал «Нет, ввести ещё раз»
- **THEN** система просит ввести название региона снова

### Requirement: Классификация статьи по региону
Каждая статья SHALL иметь поле `region` (код субъекта, `federal`/`all` для федеральных), выведенное из `title`/`summary` (fallback 1000 знаков `original_text`) по тому же справочнику + леммам. Если регион не найден — `federal`.

#### Scenario: Региональный закон распознан
- **WHEN** заголовок содержит «Губернатора Забайкальского края»
- **THEN** `Article.region` = `75` (Забайкальский край)

#### Scenario: Федеральный закон
- **WHEN** заголовок не содержит упоминания субъекта
- **THEN** `Article.region` = `federal`

### Requirement: Фильтрация по региону
Система SHALL отправлять уведомление и показывать статью в `/latest` только если `Article.region` совпадает с фильтром пользователя (`all`/`federal` считается подходящим для «Все») или фильтр «Все». Фильтр по региону SHALL комбинироваться с фильтрами по силе и сфере (AND).

#### Scenario: Уведомление отфильтровано по региону
- **WHEN** у пользователя фильтр `Забайкальский край` и пришла статья `region=77` (Москва)
- **THEN** уведомление не отправляется

#### Scenario: Уведомление прошло по региону
- **WHEN** у пользователя фильтр `Забайкальский край` и пришла статья `region=75` или `federal` (если «Все»)
- **THEN** уведомление отправляется (если совпали и сила/сфера)

### Requirement: Онбординг-визард шага «Регион»
Визард SHALL показывать шаг «Регион» как текстовый ввод + подтверждение, состояние SHALL сохраняться между попытками. Визард SHALL вызываться как шаг 3/3 онбординга (после «Сфера» и «Сила») и из `/settings` → `Регион`, с опцией `Пропустить → Все регионы` и повторным вводом до 3 раз.

#### Scenario: Успешный ввод региона
- **WHEN** новый пользователь на шаге «Регион» ввёл «Москва» и подтвердил «Да»
- **THEN** система сохраняет фильтр и завершает визард

#### Scenario: Пропуск региона
- **WHEN** пользователь нажал `Пропустить → Все регионы`
- **THEN** фильтр остаётся «Все»

#### Scenario: Повторный ввод
- **WHEN** система не распознала ввод и пользователь нажал «Нет»
- **THEN** показывается просьба ввести ещё раз
