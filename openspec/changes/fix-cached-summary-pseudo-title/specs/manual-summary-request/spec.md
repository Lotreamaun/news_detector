## ADDED Requirements

### Requirement: Псевдозаголовок не показывается как заголовок закона

Если для закона, запрошенного не из ленты, в БД сохранена запись, заголовок которой пуст или совпадает с его `external_id` (псевдозаголовок), система SHALL обращаться с такой записью как с законом с неизвестным заголовком во всех ответах принудительной саммаризации (`/summary` и кнопка «Сделать саммари»). `external_id` SHALL НЕ показываться жирным как заголовок. Формат ответа SHALL совпадать с форматом, который пользователь получает при первом запросе этого закона:
- есть саммари — текст саммари, строка `id: <external_id>` для сверки, ссылка на оригинал на портале и кнопка «Полный текст» (если WebApp сконфигурирован);
- саммаризация не удалась — сообщение с причиной неудачи, `external_id` и ссылкой на оригинал, без жирного псевдозаголовка.

Для записей с настоящим заголовком поведение не меняется: заголовок выводится жирным.

#### Scenario: Повторный /summary для закона не из ленты
- **WHEN** пользователь вызывает `/summary <external_id>` для закона, который ранее был саммаризирован через `/summary` вне ленты (в БД есть запись с саммари и заголовком, равным `external_id`)
- **THEN** пользователю приходит сохранённое саммари без повторного обращения к LLM, строка `id: <external_id>`, ссылка «Читать на портале» и кнопка «Полный текст»; `external_id` не выводится жирным заголовком

#### Scenario: Неудача для записи с псевдозаголовком
- **WHEN** пользователь вызывает `/summary <external_id>` для записи с псевдозаголовком без саммари, и саммаризация не удалась (лимит исчерпан, текст недоступен или непредвиденная ошибка)
- **THEN** пользователю приходит сообщение с причиной неудачи, `external_id` и ссылкой на оригинал на портале, без жирного псевдозаголовка

#### Scenario: Успешная повторная саммаризация записи с псевдозаголовком
- **WHEN** запись с псевдозаголовком есть в БД без саммари (например, прошлая попытка закончилась отказом языковой модели), и новая попытка `/summary` сформировала саммари
- **THEN** пользователю приходит саммари, строка `id: <external_id>`, ссылка на портал и кнопка «Полный текст»; `external_id` не выводится жирным заголовком

#### Scenario: Закон с настоящим заголовком
- **WHEN** пользователь вызывает `/summary <external_id>` для закона из ленты, у которого в БД сохранён настоящий заголовок
- **THEN** ответ содержит этот заголовок жирным, как и раньше
